# Hello! I'm xxx

一个可复用的交互式个人简历与项目展示网站模板。

它不只是把传统简历搬到网页上，而是通过清晰的页面、自然的动效和可视化项目内容，帮助访客快速了解“你做过什么、怎么做、取得了什么成果”。后续还会逐步加入面试问答、工作辅助和求职匹配等 AI 能力。

## 项目特点

- **动态简历**：展示个人介绍、核心技能、工作经历和代表项目。
- **项目可视化**：通过截图、视频、架构图、流程图和成果数据讲清楚项目。
- **内容驱动**：个人信息、项目资料和页面配置与组件代码分离。
- **易于复用**：替换配置、内容和素材即可生成自己的网站，无需修改页面组件。
- **AI 可扩展**：逐步支持基于公开资料的面试问答、个人工作辅助和求职匹配。
- **简单直接**：面向公开个人网站，不包含登录、注册等不必要的用户系统。

## 技术栈

| 部分 | 技术 |
| --- | --- |
| 页面框架 | Next.js、React |
| 开发语言 | TypeScript |
| 样式 | Tailwind CSS、CSS Variables |
| 动画与交互 | Motion；复杂场景按需使用 GSAP、Three.js |
| 内容管理 | MDX、YAML |
| 内容校验 | Zod |
| AI 接入 | Next.js 服务端接口、模型 API |
| 部署 | Vercel 或其他支持 Next.js 的平台 |

项目默认不使用独立后端和数据库。公开内容通过文件管理；AI 所需的少量服务端逻辑与网站共用同一个 Next.js 项目。

## 功能规划

1. **动态简历**：简历首页、项目列表和项目详情。
2. **项目可视化**：产品截图、演示视频、架构图、流程图和成果展示。
3. **面试问答 Agent**：围绕公开经历进行连续问答，并提供项目依据。
4. **个人工作 Agent**：按照个人工作方式辅助拆解需求、任务、优先级和风险。
5. **求职匹配 Agent**：分析 JD，匹配个人经历，生成岗位差距和面试准备建议。

## 如何使用

> 当前项目处于早期搭建阶段。以下目录和使用命令是项目的统一约定，将随项目骨架逐步实现。

### 1. 安装并启动

需要安装 Node.js LTS 和 npm。

```bash
git clone https://github.com/TwoTu-Studio/Hello-I-m-xxx.git
cd Hello-I-m-xxx
npm install
npm run dev
```

启动后访问 `http://localhost:3000`。

### 2. 替换成自己的内容

项目采用“配置、内容、素材、代码分离”的组织方式：

```text
site.config.yaml          # 网站名称、导航、SEO、主题和功能开关
content/
  profile.yaml            # 个人介绍、职业方向和联系方式
  skills.yaml             # 技能及分组
  experiences/            # 工作经历
  projects/               # 项目资料，每个项目一个 MDX 文件
  work-methods.yaml       # 个人工作方法，可选
public/
  media/                  # 头像、项目截图、视频和架构图
```

通常只需要完成以下操作：

1. 修改 `site.config.yaml`，设置网站信息、主题和需要启用的模块。
2. 替换 `content/` 中的个人介绍、技能、工作经历和项目资料。
3. 替换 `public/media/` 中的图片、视频等素材，并更新内容中的引用路径。
4. 运行内容检查，确认必填字段、日期格式和素材引用正确。

无需在 React 组件中逐个修改姓名、经历或项目数据。

### 3. 检查并构建

```bash
npm run content:check
npm run build
npm run start
```

- `content:check`：检查内容结构和必要字段。
- `build`：生成生产版本。
- `start`：在本地预览生产版本。

### 4. 部署

将仓库导入 Vercel，按照默认的 Next.js 配置构建并部署即可。

如果后续启用 AI 功能，需要在部署平台配置相应的模型 API 环境变量。密钥只用于服务端，不会写入公开内容或前端代码。

## 内容与隐私原则

- 公开页面和公开问答只使用明确标记为公开的资料。
- 私人工作资料不进入公开内容索引，也不通过无权限控制的接口提供。
- AI 回答应尽量给出对应项目依据；资料不足时明确说明，不编造经历或成果。

## 设计目标

这个项目希望同时做到：

- 对访客：页面好看、交互自然，能够快速看懂个人经历与项目价值。
- 对使用者：替换简单、配置清楚，不需要理解整套源码。
- 对开发者：技术栈统一、实现成本可控，并能按阶段扩展 AI 能力。
