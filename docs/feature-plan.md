# 分阶段功能规划

## 1. 项目目标

做一个交互式个人简历网站：先通过动态简历和项目可视化讲清楚自己做过什么，再逐步加入面试问答、工作辅助和求职匹配 Agent。

## 2. 内容基础

| 内容对象 | 主要内容 | 用途 |
| --- | --- | --- |
| 个人档案 | 个人介绍、职业方向、核心技能、联系方式 | 简历首页展示 |
| 工作经历 | 公司、职位、时间、职责、代表成果 | 简历展示、岗位匹配 |
| 项目资料 | 项目背景、目标、本人职责、关键行动、难点、成果 | 项目详情、经历检索 |
| 成果材料 | 产品截图、演示视频、架构图、流程图、成果数据 | 项目可视化、回答依据 |
| 工作方法 | 工作习惯、常用流程、技术偏好、协作方式 | 个性化工作拆解 |
| 岗位分析 | JD、匹配经历、匹配度、差距、面试建议 | 求职分析记录 |

## 3. 分阶段规划

| 阶段 | 要做什么 | 主要功能 | 阶段产出 |
| --- | --- | --- | --- |
| **第一阶段：动态简历** | 把传统简历变成可浏览、可点击的项目网站 | 1. 简历首页：个人介绍、技能、工作经历、代表项目<br>2. 项目列表：展示项目简介、本人角色和核心亮点<br>3. 项目详情：展示背景、目标、本人职责、关键行动和成果<br>4. 内容维护：支持更新简历和项目，控制内容是否公开 | 一个可以发布的个人简历网站 |
| **第二阶段：项目可视化** | 让产品和技术项目更直观，不再只靠文字描述 | 1. 产品项目：产品截图、演示视频、核心功能、产品亮点和实际效果<br>2. 技术项目：架构图、流程图、技术难点、实现过程和方案取舍<br>3. 成果展示：通过图片、视频、图表和数据说明项目价值 | 一套产品型、技术型项目展示页面 |
| **第三阶段：面试问答 Agent** | 让面试官通过提问进一步了解本人经历 | 1. 围绕项目职责、技术方案、产品决策和成果进行问答<br>2. 支持连续追问和推荐问题<br>3. 回答附对应项目依据，并可跳转到项目详情<br>4. 只使用公开资料；资料不足时明确说明，不编造回答 | 一个基于公开简历和项目资料的问答助手 |
| **第四阶段：个人工作 Agent** | 根据个人工作习惯，辅助拆解新需求和新任务 | 1. 输入需求，提取目标、约束、交付物和待确认事项<br>2. 按个人工作方式拆解任务、优先级、依赖和风险<br>3. 检索相关历史项目，提示可复用经验<br>4. 支持人工修改，并沉淀确认后的工作方法 | 一个符合个人习惯的工作拆解助手 |
| **第五阶段：求职匹配 Agent** | 输入 JD，找出最匹配的个人经历，并辅助面试准备 | 1. 解析 JD 的核心职责、必备要求和加分项<br>2. 从完整经历中筛选最相关的工作和项目<br>3. 输出“JD 要求—个人经历—成果证据”匹配表<br>4. 给出综合匹配度、各项依据和岗位差距<br>5. 建议重点讲哪些经历，以及每段经历怎么讲<br>6. 提供面试追问准备和简历调整建议 | 一份针对目标岗位的匹配分析与面试准备报告 |

## 4. 实施顺序

**动态简历 → 项目可视化 → 面试问答 Agent → 个人工作 Agent → 求职匹配 Agent**

前两个阶段先把简历和项目资料整理完整，后三个阶段共用这套内容基础。公开问答只能使用公开资料；个人工作和求职匹配可以使用本人授权的完整资料。
